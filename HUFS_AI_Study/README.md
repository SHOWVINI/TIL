### Data_Science(Prof. Kim)

        - 제 1주: OT와 데이터 기초체력 기르기 Ⅰ

        통계학 이해하기, 모집단과 표본추출, 변수와 척도

        - 2주: 데이터 기초체력 기르기 Ⅱ

        데이터의 기술 통계적 측정, 확률과 확률변수, 확률분포, 가설검정

        - 3주: 데이터 분석 준비하기

        분석 프로젝트 준비 및 기획, 분석 환경 세팅하기

        - 4주: 데이터 탐색과 시각화 Ⅰ

        탐색적 데이터 분석, 공분산과 상관성 분석, 시간 시각화, 비교 시각화

        - 5주: 데이터 탐색과 시각화 Ⅱ

        분포 시각화, 관계 시각화, 공간 시각화, 박스 플롯

        - 6주: 데이터 전처리와 파생변수 생성 Ⅰ

        결측값 처리, 이상치 처리, 변수 구간화(Binning), 데이터 표준화와 정규화 스케일링

        - 7주: 데이터 전처리와 파생변수 생성 Ⅱ

        모델 성능 향상을 위한 파생 변수 생성, 슬라이딩 윈도우 데이터 가공, 범주형 변수의 가변수 처리, 클래스 불균형 문제 해결 (언더샘플링과 오버샘플링), 데이터 거리 측정 방법

        - 8주: 중간 고사

        - 9주: 통계 기반 분석 방법론

        분석 모델 개요, 주성분 분석(PCA), 공통요인분석(CFA), 다중공선성 해결과 섀플리 밸류 분석, 데이터 마사지와 블라인드 분석, Z-test와 T-test, ANOVA(Analysis of Variance), 카이제곱 검정(교차분석)

        - 10주: 머신러닝 분석 방법론 Ⅰ

        선형 회귀분석과 Elastic Net (예측모델), 로지스틱 회귀분석 (분류 모델), 의사결정나무와 랜덤 포레스트 (예측/분류 모델)

        - 11주: 머신러닝 분석 방법론 Ⅱ

        선형 판별분석과 이차 판별분석 (분류 모델), 서포트벡터머신(SVM) (분류 모델), KNN (분류, 예측 모델)

        - 12주: 머신러닝 분석 방법론 Ⅲ

        시계열 분석 (예측모델), k-means 클러스터링 (군집 모델), 연관규칙과 협업 필터링 (추천 모델), 인공 신경망 (CNN, RNN, LSTM)

        - 13주: 모델 평가 Ⅰ

        학습 셋, 검증 셋, 테스트 셋과 과적합 해결, 주요 교차 검증 방법, 회귀 성능 평가지표

        - 14주: 모델 평가 Ⅱ

        분류, 추천 성능 평가지표, A/B 테스트와 MAB, 유의확률의 함정, 분석가의 주관적 판단과 스토리텔링

        - 15주: 기말 고사

### Artificial_Intelligence

        - 1주: OT, 인간 지능을 흉내 내는 인공지능

        지능이란, 인공지능의 역사, 인공지능의 현재와 미래, 인공지능 만들기

        - 2주: 파이썬으로 시작하는 인공지능

        영리한 프로그래밍 환경: 아나콘다, 인공지능 프로그래밍 예제, 인공지능 프로그래밍을 위한 파이썬 기초

        - 3주: 기계 학습과 인식 Ⅰ

        기계 학습 기초, 인공지능 제품의 설계와 구현, 데이터에 대한 이해, 특징 추출과 표현

        - 4주: 기계 학습과 인식 Ⅱ

        회귀의 개념을 이해, kNN 알고리즘을 이해, K-means 알고리즘을 이해

        - 5주: 신경망 기초

        퍼셉트론의 원리, 사람의 학습과 신경망의 학습, 퍼셉트론 학습 알고리즘, 다층 퍼셉트론, 오류 역전파 알고리즘

        - 6주: 딥러닝과 텐서플로

        딥러닝의 등장, 텐서플로 프로그래밍 기초, 딥러닝의 학습 전략, 딥러닝이 사용하는 손실 함수, 딥러닝이 사용하는 옵티마이저

        - 7주: 컨볼루션 신경망과 컴퓨터 비전 Ⅰ

        컨볼루션 신경망의 동기와 전개, 컨볼루션 신경망의 구조와 동작, 컨볼루션 신경망의 학습, 컨볼루션 신경망 프로그래밍, 컨볼루션 신경망의 시각화, 딥러닝의 규제, 전이 학습, 물체 검출

        - 8주: 중간고사

        - 9주: 지능 에이전트

        지능 에이전트 시나리오, 지능 에이전트 만들기, 고급 인터페이스를 갖춘 지능 에이전트, 지식 표현과 추론

        - 10주: 시계열 데이터와 순환 신경망

        시계열 데이터의 이해, 순환 신경망, LSTM으로 시계열 예측하기, 자연어 처리

        - 11주: 강화 학습과 게임 지능

        강화 학습의 원리와 응용, 최적 정책과 가치 함수, 동적 프로그래밍, 학습 기반 알고리즘, DQN

        - 12주: 생성 모델과 창작

        확률적 생성 모델, 오토인코더, 생성 적대 신경망, 응용 시나리오: 인공지능 패션 디자인

        - 13주: 공간 탐색과 문제 해결

        상태 공간, 맹목 탐색, 최고 우선 탐색, A* 알고리즘, 미니맥스 알고리즘, 몬테카를로 트리 탐색 알고리즘

        - 14주: 설명 가능 인공지능

        결정 트리의 설명 능력, 설명 가능 인공지능의 수준과 어려움, 컨볼루션 신경망의 설명 능력, GradCAM 프로그래밍

        - 15주: 기말고사
